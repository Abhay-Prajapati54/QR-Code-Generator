# QR Code Generator

A simple and responsive **QR Code Generator** built using HTML, CSS, and JavaScript.<br>
Enter any text or URL and generate a QR code instantly.<br>

## Features

- Generate QR codes from text or URLs.<br>
- Simple and clean user interface.<br>
- Responsive design.<br>
- Input validation.<br>
- Uses QR Server API.<br>

## Technologies Used

- HTML5<br>
- CSS3<br>
- JavaScript<br>
- QR Server API<br>


## Project Structure<br><br>

QR-Code-Generator/<br>
├── index.html<br>
├── style.css<br>
└── script.js<br><br>

## How to Use<br>

1. Enter your text or URL in the input field.<br>
2. Click the **Generate QR** button.<br>
3. Your QR code will be displayed instantly.<br>

## Project Purpose

A beginner-friendly project to practice **JavaScript DOM manipulation, event handling, and API integration**.<br>
